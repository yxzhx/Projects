# Proyectos de Programación y Algoritmos: Fibonacci-2048 y Algoritmos de caminos y grafos

Colección de implementaciones algorítmicas y scripts desarrollados en Python dentro del marco académico del **Grado en Matemáticas (Universidad Complutense de Madrid)**.

---

## 📄 Archivos del Repositorio

- `fibo_2048.py`: Implementación del juego 2048 combinado con la secuencia de Fibonacci / lógica de tableros.
- `lab_template_caminos.py`: Plantilla y funciones para el análisis y búsqueda de caminos en estructuras de grafos/mallas.
- `test_env_caminos.py`: Entorno de pruebas de entorno y validación para los algoritmos de caminos.

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Python 3
- **Conceptos:** Algoritmos, Estructuras de Datos, Análisis de Complejidad

---

## 🚀 Cómo ejecutar los scripts

```bash
# Ejecutar la prueba del entorno de caminos
python test_env_caminos.py

# Ejecutar el juego / script de Fibonacci-2048
